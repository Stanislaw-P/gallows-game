# 🎮 Игра «Виселица» на C# WinForms

Простой и наглядный десктопный проект классической игры **«Виселица»**, разработанный на языке C# с использованием графического интерфейса Windows Forms. Проект создан в образовательных целях для демонстрации базовых принципов программирования.

## 🎯 Описание проекта
Приложение представляет собой оконную игру, в которой пользователю необходимо по буквам отгадать загаданное слово за ограниченное число попыток. Каждая ошибка отображается графически в виде смены изображения виселицы (от пустого блока до завершения рисунка).

---

## 📜 Правила игры
* Компьютер случайным образом загадывает слово из заранее подготовленного словаря.
* Слово отображается на экране в виде замаскированных символов (подчеркиваний `_`).
* Игрок нажимает на виртуальные кнопки с буквами на экране.
* Если буква есть в слове — она открывается на соответствующих позициях.
* Если буквы нет — засчитывается ошибка, уменьшается количество оставшихся попыток и обновляется картинка виселицы.
* **Цель:** Отгадать все буквы слова до того, как закончится лимит попыток.

## 🏗 Пошаговая структура реализации

Разработка проекта разбита на 6 логических блоков:

1. **Проектирование UI (Интерфейс):**
   * Создание формы, добавление меток для слова и статуса попыток (`Label`).
   * Размещение зоны отображения виселицы (`PictureBox`).
   * Создание виртуальной клавиатуры (кнопки с русскими буквами) и кнопки перезапуска игры.

2. **Состояние игры и инициализация:**
   * Объявление массива слов и переменных состояния (`currentWord`, `displayWord`, `numberAttempts`).
   * Реализация метода `StartNewGame()`, выбирающего случайное слово и создающего маску из подчеркиваний.

3. **Логика обработки клика по букве:**
   * Создание единого обработчика события `Click` для всех буквенных кнопок с использованием параметра `sender`.
   * Проверка наличия выбранной буквы в загаданном слове с помощью цикла `for`.

4. **Отрисовка виселицы (Визуал ошибок):**
   * Пошаговая смена изображений виселицы (`step1.jpg` — `step7.jpg`) в зависимости от количества допущенных ошибок.

5. **Проверка победы и поражения:**
   * Контроль завершения игры: проверка на отсутствие символов маски `_` (победа) или достижение лимита попыток (поражение).
   * Блокировка клавиатуры по окончании партии.

6. **Рефакторинг и финализация:**
   * Выделение повторяющегося кода во вспомогательные методы.
   * Обработка возможных ошибок при загрузке графических файлов.
